# Security Policy

## Supported Versions

This project is currently maintained as an educational/project release.

| Version | Supported |
| --- | --- |
| Current release | Yes |
| Older releases | No |

## Reporting a Vulnerability

If you discover a security vulnerability in VulnScan Lite, please do not publicly disclose the details before the issue has been reviewed.

Please report security issues privately through GitHub's security reporting features, if enabled for the repository, or contact the repository owner through their GitHub profile.

Include:

- A clear description of the issue
- Steps to reproduce it
- The affected component or file
- Potential impact
- Any suggested mitigation

Please do not include passwords, private keys, tokens, or other sensitive information in a report.

## Responsible Use

VulnScan Lite is intended for authorized passive security assessment.

Do not use the project to scan systems without permission.
